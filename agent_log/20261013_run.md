## Step 2.3 — Decision and resumption

- Daniel approved the observed-baseline-plus-model-change option after review of Masselot's archived code.
- Masselot uses ERA5 plus historical GCM data for calibration through 2014 and calibrated scenario GCM temperatures from 2015 onward; he does not splice observed ERA5 daily temperatures into 2015–2019 projections.
- The moving P97.5 is therefore anchored as `ERA5 P97.5(2000–2014) + [calibrated GCM rolling P97.5(t-15:t-1) - calibrated GCM P97.5(2000–2014)]`.
- This is not a special case for 2015. It removes each GCM's residual baseline tail offset while preserving its simulated evolution. In 2015 the rolling GCM window is exactly 2000–2014, so the change term is zero and the anchored threshold equals the static ERA5 threshold by construction.
- The no-CC branch remains fixed at the static threshold. Negative modelled changes are clamped to zero relative to the static threshold.
- This follows Masselot's calibration principle (observed historical level plus simulated change), although Masselot did not implement this paper's three-way heat split.
- The method is recorded in the Part 01 header, README Method choices table, pipeline data contract and moving-threshold diagnostic output.
- The Madrid gate will now be rerun before Parts 02–04 or any batch begins.
